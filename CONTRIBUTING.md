# Contributing

This repository is intentionally narrow. Contributions should improve the reproducibility or evidence quality of the loopback-bind observation without broadening the project into a general Codex sandbox test suite.

## Good contributions

- reproduction results from clearly identified Codex/macOS versions,
- minimal corrections to the probe or documentation,
- sanitized evidence that distinguishes observed facts from interpretation,
- comparisons showing a material behavior change across versions.

## Please avoid

- raw private logs,
- credentials, tokens, usernames, hostnames, or private paths,
- unrelated project code,
- instructions that disable sandboxing or broadly expand permissions merely to make the probe succeed,
- claims that a specific policy layer caused the denial unless the evidence establishes that attribution.

When reporting a result, include the smallest environment/version information necessary and state whether the bind returned success or an error.
